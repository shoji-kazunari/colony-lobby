# colony-lobby

宇宙コロニーの中央ターミナル「第七ターミナル」を歩き回る、ローポリ3Dのブラウザ作品（試作）。
昔のオンラインゲームの「街にいる感じ」（空間・音・人の気配）を再現することを目指している。
特定のゲームの素材・名称は使わず、雰囲気だけを参考にしたオリジナル作品。

## ターミナルの作り

吹き抜けを囲んで4つの階が重なる。上の階ほど吹き抜けの穴が大きく、1Fが一番広い。

| 階 | 名前 | 中身 |
|---|---|---|
| 4F | 展望ラウンジ | 窓ぎわのソファ、夜景、ラウンジバー、マイルーム受付 |
| 3F | ショッピングモールB | 武器・防具・合成・素材・ディスク・修理 |
| 2F | ショッピングモールA | ウェア・パーツ・アクセサリー・雑貨・ヘアサロン・ルームグッズ |
| 1F | イベント広場 | 噴水のステージ、天井からの光、ヤシの花壇、転送ゲート、カウンター |

- 1F→2Fは広場の2本のエスカレーター、2F→3Fと3F→4Fは吹き抜けを渡る空中ブリッジでつながる
- お店・ミッション・転送ゲートはまだ見た目だけ（話しかけると「準備中」と返ってくる）

## 遊び方

`index.html` をブラウザで開くだけ。ビルド工程はない。

| 操作 | 内容 |
|---|---|
| WASD / 矢印キー | 移動 |
| ドラッグ | 視点を回す（上に引くと見上げる） |
| ホイール | 寄る・引く |
| Enter | チャット |
| 1 / 2 | 手を振る / 座る |
| スマホ | 画面左側で移動、右側で視点 |

## 作り

- 3D描画は Three.js r128（cdnjs から読み込み）
- 音はすべて Web Audio API でブラウザ内で生成している（音声ファイルなし）
- 周りの住人はコンピューター制御（各階を歩き回る・立ち話・ベンチ・エスカレーターや橋の往来・転送ゲートで出入り）
