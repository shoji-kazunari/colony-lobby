# colony-lobby

とある星の高台に築かれたコロニー「第七コロニー」の一角を歩き回る、ローポリ3Dのブラウザ作品（試作）。
昔のオンラインゲームの「街にいる感じ」（空間・音・人の気配）を再現することを目指している。
特定のゲームの素材・名称は使わず、雰囲気だけを参考にしたオリジナル作品。

## コロニーの作り

上から見ると鍵穴の形をしている。

- **丸い部分**：4階分の高さまで吹き抜けたイベントホール（直径120m）。壁は全面ガラス、天井はガラスのドーム。
  中央に噴水と天井からの光、奥にライブ用のステージ、ガラスぎわに外を眺めるベンチ、転送ゲート
- **四角い部分**：4階建てのモール棟。各階がホールに向かってテラスとして開いていて、
  棟の中央は細長い吹き抜け（各階に渡り廊下）。突き当たりはガラス張り

| 階 | 名前 | 中身 |
|---|---|---|
| 4F | 展望ラウンジ | 奥のガラスぎわのソファ、ラウンジバー、マイルーム受付 |
| 3F | ショッピングモールB | 武器・防具・合成・素材・ディスク・修理 |
| 2F | ショッピングモールA | ウェア・パーツ・アクセサリー・雑貨・ヘアサロン・ルームグッズ |
| 1F | イベントホール | ホール全体と、モール棟1階のカウンター（ミッション・案内・カフェ・ロッカー・イベント受付） |

- 1F→2F：ホール中央の大エスカレーター（2Fテラスへ）と、モール棟の中のエスカレーター
- 2F→3F、3F→4F：モール棟の吹き抜けを横切る長いエスカレーター
- 外は眼下に広がる夜の街、高速道路を流れる光、遠くの山並み、空に輪のある大きな惑星
- お店・ミッション・転送ゲート・ステージはまだ見た目だけ（話しかけると「準備中」と返ってくる）

## 遊び方

`index.html` をブラウザで開くだけ。ビルド工程はない。

| 操作 | 内容 |
|---|---|
| WASD / 矢印キー | 移動 |
| ドラッグ | 視点を回す（上に引くと見上げる） |
| ホイール | 寄る・引く |
| Enter | チャット |
| 1 / 2 | 手を振る / 座る |
| スマホ | 画面左側で移動、右側で視点、2本指で寄る・引く。縦・横どちらの画面でも遊べる |

カメラはキャラと紐でつながっているように動く。歩き出して紐が張ると後ろからついてきて、
カメラに向かって歩くと紐がたるみ、近づきすぎると少し下がる。

## 作り

- 3D描画は Three.js r128（cdnjs から読み込み）
- 音はすべて Web Audio API でブラウザ内で生成している（音声ファイルなし）
- 周りの住人はコンピューター制御。階ごとの通れる場所を格子で持ち、経路を探して歩く
  （立ち話・ガラスぎわで外を眺める・エスカレーターの往来・転送ゲートで出入り）
